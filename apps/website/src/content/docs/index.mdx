## What it is

Hallspeak is for churches, schools, conferences and anyone else running an event in more
than one language. It runs on a NAS or a modest home server that you own: no cloud
services, no subscription, and no account for anyone except the administrator.

## How it works

- An **Event** is one occasion — a service, a session, a talk. It has one or more
  **Channels**, in practice one per target language.
- Guests join an Event with its **PIN** or a QR code carrying it, pick a Channel and
  listen. The listener works in any modern browser, and an iOS and Android app adds
  lock-screen controls.
- Each Channel has its own **Speaker code**. Whoever holds it opens the speaker studio and
  goes live. Two interpreters sharing a Channel swap through a **handover**, so neither is
  cut off mid-sentence and the audio has no gap.
- Listeners can send an anonymous **issue report** — too quiet, too loud, static, noise,
  silence — that the interpreter sees in the studio.

Possession of a link or code is the whole authorization. Hallspeak never learns who is
listening.

## Run your own

Hallspeak ships as one Docker image that runs behind your reverse proxy. The
[installation guide](/getting-started/installation/) takes you from download to a working
first event.
